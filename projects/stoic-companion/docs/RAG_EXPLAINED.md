# RAG in Stoic Companion

Consider: “I feel anxious about things outside my control.” A prior user turn is included when forming a bounded standalone search query; only the last two user turns are appended. This deterministic rewrite avoids an extra API call and does not invent new intentions. Its limitation is that it does not resolve every pronoun; a model-based rewrite can be added behind this boundary after evaluation.

The query is embedded with the same provider/model as ingestion. Qdrant compares the query with child vectors using cosine similarity. BM25 independently searches normalized child text. An old translation may discuss power, desire and opinion rather than modern anxiety. Hybrid ranking helps only when some query vocabulary overlaps; the offline hashed model is particularly limited here.

A small editorial vocabulary bridge appends search terms for seven themes (anxiety/control, comparison, career honors, discipline, criticism/anger, grief/death and approval). Control/anxiety appends power, opinion, desire and fear. This is a search aid, not source text or a diagnosis. Debug retains the original and expanded query. Common English stopwords are excluded from lexical indexing and the demo embedding hash. The current message is retained in full; only prior query context is truncated to 1,200 characters.

For example, `enchiridion-long:I` is the actual first numbered section in Long's edition and discusses things in our power. This ID is a candidate, not a promised result for every anxious query. The executed benchmark records what was actually returned. Dense and BM25 ranks are merged with `1/(60+rank)`. An optional reranker adds `0.04 × query-term coverage`. It has zero API cost and is explicitly a lexical heuristic, not a semantic cross-encoder.

The best distinct parents supply 3–5 evidence passages, where available. Their exact child excerpts and bounded parent context are passed as untrusted JSON to GPT. A structured answer has a summary, selected IDs, explanations linked to those IDs, practical applications and a reflection question. Interpretations are distinct from quotations. The prompt disallows using book text as instructions and forbids invented attribution.

Suppose the model selects `enchiridion-long:I`. The backend first checks that the ID was retrieved, then checks that its chosen stored child is a whitespace-normalized substring of the parent. The backend—not GPT—attaches the title, George Long translator attribution, section I, source URL and quote. Clicking its card displays the surrounding parent and edition. A model requesting section XCIX or returning an arbitrary quotation is rejected.

Follow-up messages retrieve again from recent user context. The last eight messages are provided to generation. The demo runs the same source and retrieval pipeline but substitutes signed word-hash vectors and a fixed reflection template. It is labeled in the UI and is not evidence that GPT generated a personalized answer. Self-harm phrase detection bypasses retrieval and prioritizes immediate safety; the model prompt additionally covers broader danger cases. This small phrase detector is not a comprehensive crisis classifier.
