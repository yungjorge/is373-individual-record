Default live retrieval is structure-aware dense search without lexical reranking: Recall@5 0.433, MRR 0.415. Fixed/dense had slightly higher recall (0.450), while structure retained meaningful original source boundaries and had better MRR. Hybrid fell to recall 0.350 and the lexical reranker to 0.250. No chunk sizes were changed to manufacture improvement. Four broken Seneca reference IDs across three questions were corrected, with an audit trail in `eval/reference-corrections.json`; the benchmark now fails before scoring if a reference is absent. Relevance judgments still need independent human review, and paraphrase faithfulness is not proved by quote verification.

Auth0 still requires `AUTH0_DOMAIN`, `AUTH0_AUDIENCE`, and the public SPA domain/client-ID/audience fields. Use a SPA callback/logout/web origin of `http://localhost:3001`, RS256 tokens and the registered API audience; then disable guest mode and rebuild. JWT signature, expiry, issuer, audience and ownership tests remain mandatory. Public production use additionally needs shared rate/spend reservations and operational retention policies.
