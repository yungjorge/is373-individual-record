# Structure-aware chunking

Gutenberg boundary markers remove license boilerplate from indexed text; the raw file and license remain in the source archive. Meditations starts at THE FIRST BOOK and stops before APPENDIX. Only the twelve books are indexed. Roman numeral section labels are preserved as Casaubon edition numbering; they must not be presented as another translator's canonical numbering.

Long's source contains both Discourses selections and the Encheiridion. The parser separates them at the printed title. This Encheiridion has **52** headings I–LII, and some familiar numbering differs from other editions. Discourses uses its actual named headings, with no inferred original book/chapter. Seneca's three approved letters preserve their printed superscript paragraph numbers after removing footnote references, page markers and navigation. There are 5, 17 and 16 paragraphs in letters 1, 13 and 63.

Each source unit becomes a parent. Long units subdivide around 1,300 cl100k tokens, retaining the original reference and a distinct internal part suffix. Children target 280 cl100k tokens. Short passages stay intact; structure-aware splitting uses sentence/paragraph boundaries and no overlap. A single oversize sentence falls back to word boundaries. Exact `start/end` offsets slice the stored parent, and `unit_start/unit_end` locate a parent subdivision within the parsed source unit. UTF-8 bytes are never sliced at arbitrary token boundaries. Parent whitespace is only normalized for search, not rewritten in quotes.

`CHUNK_STRATEGY=fixed|recursive|structure` selects word-aligned token windows, paragraph/sentence recursive subdivision, or structure-aware sentence/paragraph subdivision. All retain original parents and provenance. The benchmark compares these strategies on the same parsed source units; fixed is not a whole-book window baseline. There is no generated contextual enrichment by default. `semantic_topics` remains empty instead of pretending model labels are source text.

The ingested demo has 412 Meditations units, 52 Encheiridion sections, 65 named Discourses selections, and 38 Seneca letter paragraphs. Long parents can become multiple stored parents. Exact counts and hashes are checked in tests; parser drift raises an error for review. A fixture that expects wording from a different translation is corrected to the actual source rather than changing stored text.
